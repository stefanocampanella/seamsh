Examples
========

Each example is a Python script, run when this documentation is built: the
figures below the code are its output. The examples that use GIS data
download it first, into the directory they run in, and write their meshes
there (``.msh`` files, which gmsh opens). The scripts and Jupyter notebooks
can be downloaded at the bottom of each page.
